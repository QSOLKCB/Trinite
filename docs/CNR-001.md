## What is compared with v0.1.0

The **only neural input** is the identical trained-native, training-exposed
16-probe capture previously retained by the v0.1.0 reference-geometry study.
The new adapter invokes Trinite's **unchanged v0.1.0**
`lattice_observation.experiment.inputs/signed_projection/score`, with:
last prompt-prefix anchor, `block.0` and `final` layers, 64 real float32
coordinates per probe, fixed signed-hash 64→3 axes (seed 29), calibration on
rows 0–7 and evaluation on rows 8–15. The same eight evaluation rows and
the same original 64D-nearest-neighbour targets are scored in every arm.

The primary comparison is exactly **20 receiver coordinates** (the original
depth-one Menger voxel coordinates) and exactly **24 undirected edges** per
arm. Graph nodes are mapped to receiver slots by the precommitted
source-selection order—not by a learned projection or anatomical embedding.
Thus the primary experiment compares **different graph topologies under a
shared arbitrary address map**, not biological/spatial homology. It deliberately
discards biological direction and synaptic weights **for the primary hop score**
while keeping them in exact input bytes and reduction provenance.

| Condition | Source and reduction |
| --- | --- |
| `baseline-menger` | Original v0.1.0 Menger depth-one face graph |
| `male-cns20` | Real 100-neuron MaleCNS sample → 20 greedily selected bodies → 24 strongest symmetric connection pairs |
| `etq101-20` | Full 101-site canonical ETQ graph → 20 greedily selected sites → 24 retained real edges |
| `etq303-20` | Full 303-state Cartesian ETQ lift → 20 greedily selected states → 24 retained real edges |
| `male-cns20-degree-rewired` | Deterministic degree-preserving swaps of selected biological graph |
| `etq101-20-degree-rewired` | Same rewire procedure over selected ETQ-101 graph |
| `etq303-20-degree-rewired` | Same rewire procedure over selected ETQ-303 graph |
| `hash-random20` | Seeded random 24-of-190 possible edges |

Node selection and all reductions depend only on prior graphs, weights and
fixed seed; never the target neural activations. Synaptic values are *counts*,
not known inhibitory/excitatory functional strengths. Comparisons against the
original **full** 100/101/303-node graphs are *not* matched-capacity tests;
the 20-node reductions are the bounded primary controls. Rewired arms preserve
the degree sequence and disclose the number of successful swaps. Null or
negative outcomes remain valid.

The primary metric is **exactly the existing v0.1.0 graph-hop score**:
`graph_hops_sum` (lower) and `same_or_adjacent` (higher), measured over the
same eight raw-native-neighbour pairs. Distance 21 denotes a disconnected
pair, not a newly inferred route. Identical receiver-coordinate identities
and identical graph edge budgets are checked across every arm. The experiment
recomputes the original Menger baseline directly—there is no newly invented
v0.1.0 historical CNR result.

## ETQ's graph walk and 303 independent fibre states

These are **separate full-graph analytic checks** in addition to the
20-node primary neural comparison:

- Full 101-site ETQ selected basis and 303-state `G_101 □ C_3` lift with
  **1,687 base edges and 5,364 lifted edges**.
- `tensorIndex=3j+a` with site `j=0..100` and independent fibre label
  `a=0,1,2`. This is 303 total states, **not 303 fibres per neuron**.
- ETQ's exact event sequence `(j,a)→(j+1 mod101,a+1 mod3)`
  has order 303 and closes its exact Gaussian phase exponent.
- The event sequence **is not automatically a graph walk**. The report
  counts its nonedge transitions. A different 303-step deterministic walk
  selects actual neighbours in the lifted graph at every step, reporting
  coverage and its final state.
- A phase-only diagonal operation cannot change state populations; there is
  **no neural amplitude/phase encoder or phase-dependent model result**.

This reuses [the original ETQ donor-parity implementation](E8-REFERENCE.md),
not copied or redefined triality or fibre semantics.

It is used strictly as a structural observation comparator—not native
training data, neuron simulation or a connected fly mind.

The optional PyArrow 21.0.0 CPython 3.12 Linux x86-64 reader is **hash-locked**
in `requirements.connectome.lock` and isolated to the new workflow.

Python-standard-library operations. The normal CPU/reference/donor workflows
are unchanged.

## Freeze, run, verify and retain

Run from the repo root with the dedicated pinned Parquet reader installed
and `PYTHONPATH=src`:

```sh
python -m pip install --require-hashes --no-deps -r requirements.connectome.lock
PYTHONPATH=src python scripts/run_cnr001.py \
  --freeze-request /tmp/cnr-request.json
# Preserve the emitted request_identity outside the run.
PYTHONPATH=src python scripts/run_cnr001.py --run \
  --request /tmp/cnr-request.json --request-identity sha256:REQUEST \
  --output /tmp/cnr-analysis.json
# Preserve the emitted analysis_identity outside the run.
PYTHONPATH=src python scripts/run_cnr001.py --verify-only \
  --request /tmp/cnr-request.json --request-identity sha256:REQUEST \
  --output /tmp/cnr-analysis.json --analysis-identity sha256:ANALYSIS
```

Both requests and analysis are created **exclusively** and never overwrite
existing bytes. The verifier independently checks externally supplied
request and analysis identities and regenerates the entire source-bound
analysis; input and output files remain unchanged. Checks include exact
original v0.1.0 capture packet identity, the original capture auditor,
upstream Git blob identities and retained dataset provenance.

The dedicated [CNR-001 GitHub Actions workflow](../.github/workflows/cnr-001.yml)
executes the real Parquet ingestion, numerical comparison, read-only replay
and a mandatory positive real-input suite. Its result and failure receipts
are uploaded separately as **post-baseline research evidence**. CI green
establishes conformance and retained result reproducibility, not learning.

## Scientific limits

**Retrospective and training-exposed:** no novel benchmark, unseen model
families, significance test, independent-host replication, biological
mechanism, model accuracy gain, better learned geometry, sparse neural routing,
changed weights or activation-phase dynamics are asserted. A lower hop sum
does not mean better reasoning. Any neural routing intervention needs a
separately frozen Phase 5 experimental protocol after the learning prerequisites
are met. Do not overwrite or re-identify the v0.1.0 release.
