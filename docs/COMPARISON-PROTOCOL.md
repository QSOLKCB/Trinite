# Three-lane / QEC detour: frozen protocol

Authorised by Trent Slade on 2026-10-09, before Phase 5. The canonical [machine protocol](../src/trinite/comparison-protocol.json) is committed before target model outcomes. A local source commit supplies ordering evidence, not independent registration. Changes after inspection require a new protocol/version and preserve these results.

Run dense, existing ternary, and classical four-state weight lanes over seeds 0, 1 and 2 on each of three workloads: the unchanged exposed formal fixture, generated qutrit syndrome/correction tasks, and generated packed-ququart syndrome/correction tasks. This is 27 cells. Within each workload/seed, architecture, initial latent weights, example order, optimiser, scored targets and update count match. Every lane gets 60 updates, batch size four, width 16, one block, context 64, geometry loss zero and the existing constant AdamW settings. The standard model is the CPU float32 dense baseline.

Four-state attention/feed-forward weights use codes {-3,-1,+1,+3}, with detached scale max(mean(abs(latent))/2, 1e-8), float64 reduction followed by float32 rounding. Threshold magnitude two chooses the inner code at equality; zero chooses +1. The surrogate passes gradients strictly inside magnitude three and zeros boundaries/outside. Embeddings, tied output, norms, latent weights, optimiser moments and computation remain float32. This is a classical quantizer, with no quantum execution or packed acceleration. Dense and ternary numerical semantics and retained model fixtures remain unchanged.

The QEC oracle is frozen at 32fdf9c88f4ac1b873c8acc4d3d54c50f87d6e0a (v170.1.0). Its actual GF(3) cyclic five-qutrit and packed two-binary-lane five-ququart decoders label every nonidentity single-site error. A separate scalar syndrome/inverse check verifies the labels. Minimal symbolic prompts teach syndrome extraction and bounded correction. Both carriers and both tasks of the same underlying error remain in one physical-support-site family; a deterministic hash rank assigns three sites to training, one to validation and one to test. The oracle's software/license is retained as a dependency, not consumed as prose training data. Admission records identify authorship, exact generation procedure, numeric rights evidence, source pins, reviewer/date and limits.

The primary metric is final-step unconstrained greedy generation of the complete exact answer and EOS on the locked test families. No teacher-forced accuracy substitutes for generation. Validation never selects updates or hyperparameters. Retain per-item outputs, train/validation/test accuracy and target loss, per-task/family results, code occupancy, quantization error, snapshots, update histories, source/environment/data identities and verified PROVENANCE evidence. Test outcomes are evaluated only after all cells finish training; failures stay in the inventory and cannot be omitted from aggregates. All datasets become visible software fixtures, so this is exploratory characterization, not fresh confirmatory generalisation evidence.

Report paired seed differences and mean/min/max across three seeds, with no significance claim. A five-percentage-point accuracy noninferiority margin, training wall ratio at most 1.25 and latent-byte ratio at most one are descriptive diagnostics, not release acceptance or evidence of packed savings. Time includes numerical training and validation; inference has one warmup and three complete fixed-prompt passes, with generation scored separately. Shared-host timing, import/process-lifetime RSS and safetensors sizes do not establish an edge-device advantage. No cross-workload aggregate hides different label lengths or task difficulty.

Geometry is secondary and uses training prompts only: final-layer states for every prompt byte, excluding BOS/EOS, with native float32 coordinates promoted losslessly to binary64. Select the first three semantic identities per family/task by content identity, retaining both carriers. Compare same item across carriers against different items in the same carrier, averaging family/task contrasts equally. Use the unmodified pinned order-one arclength/cosine kernel. Controls are a deterministic one-sided right-path hash permutation and deterministic Rademacher vectors, seed 17. This new protocol does not rewrite Phase 4's paired-reversal control or its negative results. Capture/control analysis cannot update weights, optimiser, example order or RNG.

TRI-I01–I14 remain applicable. Safe comparison snapshots use their own schema and bind the exact plan, dataset, source and environment; old native checkpoints retain their original source compatibility requirements. Retained numerical equality/replay checks, independent quantizer/oracle checks, family isolation, malicious-input rejection, observer isolation and all existing Python CI lanes are gates. Phase 5 intervention, larger models, phase embeddings, quantum hardware, packed inference and broader corpus intake remain deferred.
