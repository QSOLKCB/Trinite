# Retained generalization diagnostic protocol

The [machine protocol](../src/trinite/generalization-protocol.json) was frozen at
`9924e82047b728e229094c37f5714bb268ebe6a3` before this diagnostic report. The
parent learning results were already public. This is a post-hoc descriptive
increment, not preregistration of a fresh capability experiment.

Bind the corrected learning request, summary and evaluation decision to their
exact retained identities. Execute the existing authoritative learning verifier
fresh, with `summarize(..., publish=False)`, before consuming any prediction.
It verifies closed upstream evidence, safe named checkpoints, regenerated final
train/test predictions, losses, pairing and the complete summary. Archived
verification-success files never authorize this stage. A changed, missing,
failed or unmatched parent rejects the entire diagnostic.

Retain all 27 cells. Count each split by task, carrier and whether its exact
answer appeared in that task's training rows. Record training answer vocabulary,
unseen held-out answers and prompt bytes. Partition outputs into exact,
wrong answer, missing EOS, misplaced special token and non-ASCII byte cases.
The answer-with-EOS count is an explicit sanity check on the exact count.

For folds, also count complete canonical count/sum/squares components. For
traversal, count complete canonical address coordinates. Require one final EOS,
strict ASCII and the complete original output grammar. Every malformed,
unfinished or noncanonical body receives zero component credit. Components
are supplementary diagnostics and cannot replace the original exact-answer/EOS
learning thresholds or rescue a failed task.

Prepare scalar count/sum/squares and traversal-value/x/y/z targets from the same
finite parent facts. Keep arithmetic as an unchanged-text control and retain
other lattice tasks. Every child and both carriers inherit their parent's family
and split, with content-bound source revision and transformation lineage.
Procedural generator labels and an independent histogram/modular oracle must
agree; the independent prompt parser checks rendered meanings. No external
content, model-generated labels, new families or held-out-to-training movement.

Freeze a separate matched training/exposure/checkpoint/gate protocol before
training this preparation. This stage does not choose a model, training budget,
geometry intervention or release. All learning/format/Phase 5/release gates stay
false regardless of supplementary component counts.

The fresh worker allows 1,200 seconds and scans at most 4,096 run entries and
512 MiB of files. Input inventories must match before and after verification and
analysis. It writes only to a new disjoint output directory. The pinned upstream observer
binds the request, parent receipts, report and complete scalar outputs; fresh
re-verification checks every root copy against that closed evidence. Timeout and failure
retain available stdout/stderr and partial outputs; read-only verification never
writes to the parent or diagnostic output. This assumes stable local directories,
not a hostile concurrent-filesystem snapshot or crash-recovery store.

Numerical replay inherits the parent's strict source and environment fingerprint,
including Python, CPU, kernel and packages. An incompatible host must reject;
it must not edit the recorded environment to force acceptance. Routine CI tests
contracts with local small fixtures and does not claim independent-host replay
of the retained matrix. Final prediction/loss regeneration is not independent
re-execution of every optimizer update or fresh confirmatory evaluation.
