# TRI-GEO-OBS-001: frozen descriptive observation

This Phase 4 protocol is frozen before inspecting Trinite geometry outcomes. The repository commit containing this document and configs/geometry-observation.json is retained as the protocol revision. A separate freeze-observation request binds the exact input checkpoints before extraction. Local clocks and hashes alone do not establish independently timestamped public registration.

Use the unchanged admitted formal-v1 training split (six modulus families, three distinct formal items per family, two carriers per item), the Phase 3 seed-0 tiny plan, and its elected step-60 dense and ternary checkpoints. Match initialization, plan, inputs and environment. No test labels, checkpoint election, optimizer step or geometry loss is introduced. All fixtures are software-visible, and training exposure is verified/exposed for this split. This is a descriptive OBSERVATION with result_status=inconclusive for the broader reasoning hypothesis.

Capture prompt bytes only at final and block.0. The primary layer is final; block.0 is a predeclared diagnostic. Each point is a native float32 hidden state at one non-special UTF-8 byte-token position in a single causal forward. Context is cumulative prefix, pooling none, transformation identity, no KV/cache reuse. Stored coordinates use exact float.hex strings, promoted losslessly to binary64 for analysis. Token IDs, full tokenizer byte spans, selected positions, source text and checkpoint/model/layer/environment/instrument identities are retained. BOS/EOS/PAD states are excluded. Prompt answers are never fed to this extraction.

Within each modulus family, compare the three same-item/different-carrier pairs and the six same-carrier/different-item pairs. Different items vary formal operands; this is not a claim that operation type or logical structure has been independently varied. Align paths by the pinned arclength rule to max(left count,right count), then use mean order-1 cosine with the upstream exact-zero convention. Primary contrast is the mean of the first three similarities minus the mean of the six control similarities. Average the six family contrasts equally. Retain every pair and family, plus family min/max; report no inferential interval or p-value. One contrast per lane is primary; every other value is diagnostic, with no post-hoc layer/metric election.

Apply the same comparisons to reversed token order (order sensitivity) and SHA-256-derived Rademacher vectors (deterministic synthetic null, seed 17, independent of global RNG). The null keeps each trajectory's length and width and is labelled SIMULATION within the observed result. Retain path length, forward differences of orders 1/2, every Menger curvature, and explicit unavailable values for empty summaries. Synthetic tests cover line, circle, null, exact-zero, near-collinearity, scale/translation, alignment and tiny/overflow cases against QSOL-GEO-REASON at e770f585bf3136b47a657772156116d5f02b1e77. No projection or alternate serving backend is admitted.

An exclusion never disappears silently: missing/incompatible/nonfinite captures, unsupported pins, changed requests or over-budget inputs fail the run and retain an error report. An observer error preserves computational artifacts but rejects evidence eligibility. Maximum retained capture JSON is 4 MiB total, context 32, hidden width 16, 72 prompt captures with two layers each, and 120 seconds checked between stages/items/pairs. Process RSS and observer overhead are recorded separately; this is not a hard OS timeout or edge benchmark. Quality/cost margins are inapplicable because this phase changes no model and makes no task-improvement claim.

Null/negative contrasts and every diagnostic remain visible. Reproduction within the frozen software/hardware scope tests replay, not independent replication. Independent replication, fresh confirmatory evaluation and any geometry training intervention remain later work.
