# External reference geometry protocol v1

Frozen before model outputs. This separate descriptive study compares the retained
arithmetic seed-0 dense Trinite checkpoint with pinned Qwen3-0.6B stock and with
a SYSTEM-only Modelfile-derived profile. Transformers CPU hidden-state capture
is the backend; this does not certify an Ollama run or arbitrary Modelfiles.

The executable contract is [reference-geometry-protocol.json](../src/trinite/reference-geometry-protocol.json).
Probes are generated visible training examples, selected before outcomes by
family, operation and paired carrier. All sixteen outputs remain visible,
including errors. First-block and final-normalized states use prompt-only causal
UTF-8 prefix anchors. Tokenizers differ; actual rendered inputs and alignments
are retained. Answer tokens are never used to select hidden states.

Linear CKA compares centered sample geometry across unequal hidden widths.
Within-space distance matrices, paired-carrier distances and prefix path lengths
are descriptive diagnostics. The independent Fraction implementation checks CKA
squared and squared distances at a frozen 1e-12 absolute-plus-relative tolerance.
Degenerate energies yield unavailable values. No projection, best-layer choice,
model ranking or significance claim is allowed.

Three verification routes cover bytes, independent arithmetic and fresh process
replay. Each condition and the derived comparison receive separate closed
PROVENANCE bundles. Retained verification receipts must match current verification
bytes. Large model weights remain outside bundles: acquisition and every capture
stream-check their pinned digests. Their manifest is retained; weights are not
misrepresented as bundled content. Original admission and source-bound native
checkpoint readers remain authoritative.

External training exposure is unknown. This study cannot establish causal
mechanisms, matched compute or generalization, and does not reopen the blocked
scalar learning experiment or authorize held-out scoring or geometry training.

Affected boundaries: I-02, I-03, I-05 through I-14; existing native numerical
operations, admission policies and historical protocols are unchanged.
