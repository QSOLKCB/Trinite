# Matched scalar curriculum experiment

Freeze this [machine protocol](../src/trinite/scalar-learning-protocol.json) before
new training outcomes. Use the exact independently checked scalar preparation
from PR #14: arithmetic unchanged texts, fold count/sum/squares and lattice
traversal value/x/y/z, retaining the other lattice tasks and every parent family
split. This is visible development data, not fresh confirmatory evidence.

Train all 27 fresh CPU float32 workload/seed/lane cells. Reuse the native model,
initializer, AdamW, loss and update loop. Fix 4,096 updates, batch eight, constant
0.001, the existing clipping/optimizer settings, 524,288 scored-target ceiling,
480-second numerical invocation bound and 600-second training worker deadline.
Rotate dense/ternary/four-state execution order by seed. Geometry loss is zero.

Rank parents by the previous canonical seed/item hash of `ordering_identity`.
Visit scalar siblings in fixed count/sum/squares or value/x/y/z order and cycle
the complete admitted child list. Arithmetic therefore preserves its numerical
parent exposure. Scalar tasks change exposure versus the composed corpus;
matching applies across the new lanes, not to that historical experiment.
Validation-history entries use training rows only. Select the final update.
No early stopping, held-out tuning, corpus addition or outcome-driven schedule.

Every training worker terminates before any held-out model call. A fresh matrix
worker verifies all closed bundles, exact retained verification receipts, safe
named model/optimizer checkpoints, actual training predictions/loss and pairings.
Publish its decision before scoring. Missing, failed or unmatched cells block
all held-out scoring; every dense training task must reach 90% exact answer/EOS
in all seeds. Retained verification success never authorizes a later invocation.

Scalar held-out gates are 50% exact answer/EOS and ten percentage points above
the per-task training-majority baseline in every dense seed. Report per-task
counts, correlated family macro and paired lane differences/costs descriptively.
Sibling projections and carriers are not independent samples. Complete scalar
answers remain primary; partial components cannot rescue these gates.

Both evaluation and fresh summary verification have separate 1,200-second worker
bounds. Retain completed, blocked, failed, timed-out and partial outputs; keep
the original output if summary publication fails. A manual CPU workflow allows
360 minutes, including the 310-minute worker envelope and retention headroom.
Runner cancellation/loss can still interrupt evidence retention. Stable local
directories are required; this is not a concurrent hostile filesystem snapshot.

Requests bind actual source, protocol, exact corpus/admission bytes, prior
diagnostic references and the locked CPU environment. Safe checkpoints bind the
same context, complete schedule, progress, named tensors and AdamW moments.
Same-environment interrupted replay and final prediction/loss regeneration are
distinct from independent-host replication and complete optimizer replay.

This experiment does not score original composed outputs. Scalar success does
not close their learning-adequacy gate or choose a format. Original composed
assessment requires its own declared protocol. Phase 5, release, structure/algebra
expansion and scaling stay blocked; all historical negative evidence is preserved.
Affected requirements: TRI-I02, I03, I05, I06, I07, I08, I10, I11, I12, I13 and I14.
