# Trinite

An inspectable, ternary-weight edge AI research project: small models, curated data, geometric reasoning experiments, and PROVENANCE observation.

**Status: Phase 2 reference model implemented.** Matched dense and ternary CPU decoders, quantizer/gradient checks, causal and padding masks, tensor inventories, and bounded detached captures are available alongside the offline foundation. The reference model has 1,247,232 unique parameters. No training result, edge benchmark, or reasoning improvement has been demonstrated.
