An inspectable, ternary-weight edge AI research project: small models, curated data, geometric reasoning experiments, and PROVENANCE observation.

**Status: Phase 4 geometry measurement implemented.** Matched dense and ternary CPU decoders support native training, safe replay, detached prompt captures, and analysis with a pinned QSOL-GEO-REASON kernel and PROVENANCE observer. The [three-lane/QEC comparison detour](docs/COMPARISON.md) adds an opt-in classical four-state lane and exact generated QEC tasks before Phase 5. Its 27-cell run completed; all lanes scored zero held-out complete answers under the tiny frozen budget, leaving format selection inconclusive. The [foundations increment](docs/FOUNDATIONS.md) adds independently checked arithmetic, folds and symbolic lattice tasks with a verified learning gate before Phase 5. Its 27-cell run verified, but dense training failed the gate, so held-out scoring stayed blocked. The [training-only convergence sweep](docs/CONVERGENCE.md) completed with no learning-rate candidate clearing all training gates. The subsequent [longer training-only budget](docs/BUDGET.md) passed per-task training checks in all nine dense cells; the subsequent [matched learning/evaluation matrix](docs/LEARNING.md) completed all 27 cells, but every dense seed failed a held-out task, so learning adequacy, format selection and Phase 5 remain blocked. The [generalization diagnostic](docs/GENERALIZATION.md) adds fresh parent verification, failure/coverage counts and independently checked scalar curriculum preparation; the [matched scalar curriculum experiment](docs/SCALAR-LEARNING.md) completed all 27 training cells, but dense fold sum missed its training gate in all three seeds, so held-out scoring stayed blocked. The [training-only fold-sum exposure increment](docs/FOLD-EXPOSURE.md) completed nine verified dense runs; extra consecutive sum exposure worsened results and no candidate cleared all training gates. The [fold-order control](docs/FOLD-ORDER.md) completed six verified runs at equal exposure; neither parent-grouped nor mixed-task order cleared the sum training gate in any seed. Original composed-output learning adequacy and Phase 5 remain blocked. The separate [maths curriculum pilot](docs/MATHS.md) adds independently checked finite maths and exact linear algebra, with a paired legacy control and explicit exploratory held-out diagnostics. The [external reference geometry comparison](docs/REFERENCE-GEOMETRY.md) adds pinned Qwen stock and SYSTEM-only Modelfile-derived internal-activation captures, independent arithmetic verification and fresh-worker replay. It is a separate visible-training-probe diagnostic. First visible-fixture geometry observations are descriptive; reasoning, intervention, and edge benchmarks remain pending. See [Phase 4 evidence and limits](docs/PHASE-4.md).
