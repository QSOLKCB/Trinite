An inspectable, ternary-weight edge AI research project: small models, curated data, geometric reasoning experiments, and PROVENANCE observation.

**Status: Phase 4 geometry measurement implemented.** Matched dense and ternary CPU decoders support native training, safe replay, detached prompt captures, and analysis with a pinned QSOL-GEO-REASON kernel and PROVENANCE observer. The [three-lane/QEC comparison detour](docs/COMPARISON.md) adds an opt-in classical four-state lane and exact generated QEC tasks before Phase 5. Its 27-cell run completed; all lanes scored zero held-out complete answers under the tiny frozen budget, leaving format selection inconclusive. The [foundations increment](docs/FOUNDATIONS.md) adds independently checked arithmetic, folds and symbolic lattice tasks with a verified learning gate before Phase 5. Its 27-cell run verified, but dense training failed the gate, so held-out scoring stayed blocked. First visible-fixture geometry observations are descriptive; reasoning, intervention, and edge benchmarks remain pending. See [Phase 4 evidence and limits](docs/PHASE-4.md).


Start with the [documentation index](docs/README.md), [architecture](docs/ARCHITECTURE.md), and [roadmap](docs/ROADMAP.md). Contributors and implementing agents should read the [operating instructions](docs/INSTRUCTIONS.md) and [invariants](docs/INVARIANTS.md) before changing the project.

Run the foundation and model checks with [GETTING_STARTED.md](docs/GETTING_STARTED.md). Foundation and evidence-verification commands use the standard library; model and training commands use the optional hash-locked CPU dependencies.
